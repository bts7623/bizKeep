# BizKeep (명함관리) — 요구사항 명세 v1

앱스토어 표시명: **BizKeep (명함관리)** / 홈 아이콘명: BizKeep / 번들 ID: com.bts.bizkeep

## 1. 목적
- 업무로 만난 사람을 폰 주소록(및 카카오톡 친구 추천)에 넣지 않고, 앱 안에서만 빠르게 찾고 바로 전화한다.
- 실물 명함을 사진으로 대체한다.
- 화면이 단순하고 가벼워서 "안 쓰게 되는" 일이 없게 한다.

## 2. 비기능 요구
- 콜드스타트 1초 내 (스플래시 없음, 시작 화면 = 목록). 캐시된 최근 목록 먼저 그리고 DB 비동기 로드.
- 검색 응답 50ms 내, 150ms 디바운스.
- 완전 오프라인. 서버 없음. 데이터는 기기 내부 저장.
- 앱 용량 60MB 내, 명함 1장 ≤ 200KB (WebP, 긴 변 1024px).

## 3. 화면 (캔버스 "BizKeep 화면 설계 v2" 기준)

### 3.1 목록·검색 (시작 화면)
- 상단: "업무 연락처 N명" 큰 숫자, 설정 버튼, 정렬 칩(최근 등록 / 이름순 / 회사순).
- **스크롤 동작**: 아래→위로 올리면 상단 영역(숫자·칩)이 접혀 숨고, 위→아래로 내리면 즉시 다시 표시 (SliverAppBar floating+snap). 하단 독은 항상 고정.
- 행: [명함 썸네일 64×40] [회사(12px) / 이름(17px 700) 직책(13px) / (메모 있을 때만) 메모 한 줄(13px, 연필 아이콘)] [통화 버튼 44px 초록 원].
  - 썸네일 탭 → 명함 이미지 전체 화면 (3.3)
  - 이름 영역 탭 → 상세 바텀시트 (3.4)
  - 통화 버튼 탭 → tel: 휴대전화 (길게 누르면 사무실)
  - 메모 없는 행은 2줄, 있는 행은 3줄.
- 하단 고정 글래스 독: 검색창(반투명 블러, 56px) + 검정 원형 + 버튼(56px).
  - 검색창은 자동 포커스 안 함. 탭해야 키보드.
  - + 탭 → 배경 블러 + 글래스 카드 2장 "명함 촬영 / 직접 입력" (3.2)
- 빈 상태(0건): 가운데 "📷 첫 명함 찍기" 버튼 하나, 안내문 한 줄 이하.
- 권한 요청은 필요한 순간에만: 카메라는 촬영 탭 시, 통화 식별은 첫 저장 직후.

### 3.2 등록 방식 선택
- 목록 위 오버레이. "명함 촬영(찍으면 바로 저장돼요)" / "직접 입력(명함이 없을 때)". X로 닫기.

### 3.3 명함 이미지 보기
- 검정 배경, 명함만 크게. 핀치 줌, 좌우 스와이프로 앞/뒷면. 하단: [상세 정보] [전화].

### 3.4 상세 (바텀시트, 화면 높이 약 92%)
- 상단 "저장됨 · 방금" 배지 (촬영 직후만), 닫기 X.
- 명함 이미지 (탭 → 3.3), 이름 26px 700 / "회사 · 직책", 우측 통화 버튼 64px 초록.
- **한 줄 메모** (이름 바로 아래): 연한 블루 박스, 탭하면 인라인 편집, 40자, 포커스 아웃 시 자동 저장. 팝업 없음.
- 필드 그룹: 휴대전화(문자 버튼) / 사무실(통화 버튼) / 이메일(메일 버튼) / 부서 / 주소(지도 버튼). 인식 불확실 필드는 노란 배경 + "탭해서 수정".
- 하단: [수정] [삭제].
- **이미 저장된 상태를 보여주는 화면이다. 확인 버튼으로 저장하는 구조가 아니다.**

### 3.5 직접 입력·수정
- 상단 [취소] 새 연락처 [저장].
- 명함 사진 추가(선택) → 찍으면 아래 칸 자동 채움.
- 섹션 순서: 기본(이름·회사·부서·직책) → **한 줄 메모** → 연락처(휴대전화·사무실·이메일·주소).

### 3.6 설정
- 알림: 수신 전화 식별 (상태·반영 건수 표시) / 문자 발신자 식별 (iOS 미지원 표기).
- 데이터: 내려받기(명함 이미지 포함 zip) / 가져오기(다른 기기 zip 일괄 등록) / 원본 이미지 보관 토글(현재 용량 표시).
- 정보: 아이콘·BizKeep 버전·한 줄 설명. (앱 설명은 여기에만)

### 3.7 통화 식별 켜기 (첫 저장 직후 1회, 이후 배너)
- 수신 화면 미리보기 목업 + 4단계 안내(설정 → 앱 → 전화 → 통화 차단 및 발신자 확인 → BizKeep 켜기) + [설정 열기] [나중에].
- 앱 복귀(resumed) 시 상태 재확인 → 켜지면 배너 자동 해제 + reloadExtension.
- "나중에" 3일 숨김, 설정에서 다시 접근.

## 4. 검색 규칙 (범위 옵션 없음)
- 대상: 이름, 회사, 부서, 직책, 휴대전화, 사무실, 이메일, 주소, 메모, OCR 원문.
- FTS5 (unicode61) + 초성 보조 컬럼. prefix MATCH. 상위 200건.
- 입력 길이 ≤2: 이름·회사만. ≥3: 전 필드.
- 자동 판별: 숫자로 시작 → 번호 필드 우선 (하이픈 무시). '@' 포함 → 이메일 우선.
- 가중치: 이름 완전일치 100 > 이름 prefix 80 > 회사 60 > 직책/부서 40 > 번호·메일 30 > 주소·메모 20 > OCR 원문 10. 동점은 최근 등록순.
- 결과 행에 매칭 필드 힌트 표시 (이름·회사 외 필드에서 걸렸을 때만, 회색 작은 글씨 "주소 · 강남구 테헤란로").

## 5. 데이터 모델
```
contacts
  id TEXT PK (UUID v4), name, company, department, title,
  phone_mobile, phone_office, fax, email, address, website,
  memo (≤40자), image_front, image_back, thumb,
  ocr_raw, source ('camera'|'manual'|'import'),
  low_confidence TEXT (JSON array of field names),
  created_at INTEGER, updated_at INTEGER
contacts_fts (FTS5 external content)
  name, company, department, title, phone_norm, email, address, memo, ocr_raw, chosung
phone_index
  phone_e164 TEXT PK, contact_id  -- 통화 식별 익스텐션 전용
```
- 내보내기: `bizkeep_YYYYMMDD.zip` = `contacts.json` + `images/<id>_front.webp` …
- 가져오기: 같은 id면 updated_at 비교해 최신 유지, 다른 id + 같은 휴대번호면 사용자에게 병합 확인(1회 일괄).

## 6. 촬영·OCR 파이프라인
0. **자동 촬영**: 카메라 화면에 명함 비율(가로 9:5) 가이드 프레임. 프레임 안에서 사각형(명함 윤곽)이 검출되고
   0.5초 이상 안정(흔들림·크기 변화 작음)되면 셔터 없이 자동 촬영 + 햅틱. 수동 셔터 버튼도 둔다(가이드 미검출 시 fallback).
   검출 중엔 프레임 모서리 색이 흰→파랑으로, 촬영 순간 짧은 플래시. (금융·SNS 앱의 신분증/카드 촬영 방식과 동일)
1. 촬영 → 검출된 사각형 기준 원근 보정 크롭(실패 시 원본)
2. ML Kit 텍스트 블록 추출 (isolate)
3. 규칙 분류: 전화/팩스 정규식(02-, 010-, +82, T/F/M/Tel/Fax), 메일, 웹, 주소(시·도·구·로·길·우편번호), 직책 사전(대표·이사·부장·차장·과장·대리·주임·사원·팀장·실장·연구원·교수·변호사·사무관·주무관…), 회사(㈜·(주)·주식회사·Co., Ltd·기관 접미), 이름(2~4자 한글, 직책 인접)
4. 신뢰도 낮은 필드는 빈칸 + low_confidence 기록 → 상세에서 노란 하이라이트
5. ocr_raw 보존 → 분류 실패해도 전문 검색은 됨

## 7. 통화·문자 식별 (플랫폼 제약)
- iOS 통화: CallKit Call Directory Extension. 번호 E.164 정규화·오름차순 필수. 사용자가 설정에서 1회 활성화.
- iOS 문자: 서드파티 표시 불가 → 미지원 명시.
- Android 통화: CallScreeningService(API 29+) 또는 PHONE_STATE + 오버레이.
- Android 문자: NotificationListenerService로 보조 알림 (2차).

## 8. 로드맵
1. 뼈대 + DB/FTS + 목록·검색·상세·입력·통화 + 헤더 숨김 + 단위테스트 (Xcode 불필요 부분 먼저)
2. 카메라 + OCR + 규칙 추출 + 즉시 저장
3. 통화 식별: iOS Call Directory → Android
4. 백업/복원, 초성검색, Android 문자
